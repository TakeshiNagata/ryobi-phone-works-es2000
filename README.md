# Ryobi Phone Works ES2000 赤外線放射温度計 macOS ドライバー

スマートフォン用アタッチメント工具「**Ryobi Phone Works ES2000（赤外線放射温度計）**」を、公式アプリ（Android APK）のリバースエンジニアリングによってプロトコル解析し、**MacBookの3.5mmオーディオジャックから直接駆動・リアルタイム温度取得**できるようにしたPythonスクリプトです。

---

## 主な機能

- **リアルタイム温度計測**: センサーから約 109 ms 周期で送られてくるテレメトリパケットを受信・AFSK復調し、摂氏（℃）・華氏（℉）およびバッテリー残量をリアルタイム表示
- **レーザーポインター単独制御**: 測定用レーザーポインターのみを点灯させるモード
- **CSVロギング機能**: 計測タイムスタンプ、日時、温度、バッテリー残量、Raw値をCSVファイルへ記録

---

## 動作要件

- **ハードウェア**:
  - MacBook / Mac（3.5mm 4極 TRRS ヘッドフォン/マイク一体型ジャック搭載機、または3.5mm TRRS USBオーディオアダプター）
  - Ryobi Phone Works ES2000（単4電池をセットしてジャックに接続）
- **ソフトウェア**:
  - Python 3.9 以上
  - `sounddevice`, `numpy`

```bash
pip3 install sounddevice numpy
```

## 使い方

### 1. リアルタイム温度計測の開始

スクリプトを実行すると、Macから起動・トリガー音声信号が出力され、センサーからの応答をリアルタイムにコンソール表示します（終了は `Ctrl + C`）：

```bash
python3 ryobi_es2000.py
```

実行画面例:

### 2. 指定時間のみ計測

```bash
# 10秒間だけ計測して自動終了
python3 ryobi_es2000.py --duration 10
```

### 3. CSVファイルへの記録

```bash
# 計測データを readings.csv に保存
python3 ryobi_es2000.py --csv readings.csv
```

### 4. レーザーポインターの点灯

```bash
# レーザーポインターを5秒間点灯
python3 ryobi_es2000.py --laser --duration 5
```

## リバースエンジニアリング仕様書

### 1. ピンアサイン（CTIA規格 3.5mm TRRS）

| 端子位置 | 信号種別 | 信号内容 / 仕様 |
| :--- | :--- | :--- |
| **Tip (Lch)** | ヘッドフォン出力 | **2,200 Hz 矩形波 / 飽和波（0 dB）連続出力**<br>デバイス内部の電源および基準クロック |
| **Ring 1 (Rch)** | ヘッドフォン出力 | **2,200 Hz バーストパルス（パルス幅 約 3.2 ms / 7 サイクル）**<br>約 109.4 ms 周期（約 9.1 Hz）で断続出力してサンプリングをキック |
| **Ring 2** | GND | グランド |
| **Sleeve** | マイク入力 | **Bell 202 準拠 AFSK 変調信号**（センサーからの温度テレメトリ返信） |

### 2. 変調仕様（Bell 202 AFSK）

- **サンプリング周波数**: 44,100 Hz
- **Mark (`0` ビット)**: 1,200 Hz（波形周期 約 833 µs）
- **Space (`1` ビット)**: 2,200 Hz（波形周期 約 454 µs）
- **判定閾値（Discriminator Threshold）**: 595 µs（周波数換算: 約 1,680.7 Hz）
  - 正ピーク間隔 $\Delta t < 595\ \mu\text{s} \implies$ **`1`**
  - 正ピーク間隔 $\Delta t \ge 595\ \mu\text{s} \implies$ **`0`**
- **パケット間ギャップ**: バースト間は $> 2.0\ \text{ms}$ の無音期間

### 3. パケットフォーマット（全40ビット）

```
[00..03]  4 bit : プリアンブル同期パターン ("1010") ※先頭1ビット欠損時は "010"
[04..08]  5 bit : モデルID / 種別 ("10101" = 21, または "00000")
[09..10]  2 bit : 制御 / ステータスフラグ
[11..30] 20 bit : 計測温度データ（符号付き固定小数点）
[31..35]  5 bit : バッテリー残量 (0〜31)
[36..39]  4 bit : チェックサム / トレーラー
```

### 4. 温度計算式

1. パケットの 11〜30 ビット目（計20ビット）を整数値 `raw_val` として抽出
2. 最上位ビット（ビット 19 / マスク `0x80000` = 524,288）で符号を判定：
   - 負（氷点下）の場合: `temp_c = - float(raw_val & 0x7FFFF) / 10.0`
   - 正の場合: `temp_c = float(raw_val) / 10.0`
3. 華氏換算: `temp_f = temp_c * 1.8 + 32.0`
